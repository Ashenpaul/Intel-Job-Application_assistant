# Intel Job Application Assistant

## Project Overview
The Intel Job Application Assistant is designed to streamline the job application process, providing users with tools to effectively manage their applications, track job openings, and prepare for interviews.

## Features
- User-friendly interface for managing job applications.
- Ability to track application status.
- Reminders for interviews and follow-ups.
- Resources for interview preparation.
- Integration with job boards for up-to-date listings.

## Tech Stack
- Frontend: React
- Backend: Node.js
- Database: MongoDB
- Deployment: Heroku

## Installation Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/Ashenpaul/Intel-Job-Application_assistant.git
   ```
2. Navigate into the project directory:
   ```bash
   cd Intel-Job-Application_assistant
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

## Deployment Guide
To deploy the application on Heroku:
1. Make sure you have the Heroku CLI installed.
2. Login to your Heroku account:
   ```bash
   heroku login
   ```
3. Create a new Heroku app:
   ```bash
   heroku create
   ```
4. Push your code to Heroku:
   ```bash
   git push heroku main
   ```
